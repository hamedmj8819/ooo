# سامانه یکپارچه مدیریت تولید و کنترل عملیات (MES) کارخانه کمپرسورسازی و بلوئرسازی

سامانه جامع تحت وب صنعتی (Manufacturing Execution System) جهت مدیریت خطوط تولید کمپرسورهای اسکرو (Screw Compressor) و بلوئرهای روتس (Roots Blower / Lobe Type) به صورت کاملاً آفلاین و متمرکز بر شبکه داخلی کارخانه (LAN).

## 🚀 ویژگی‌های کلیدی
- **کاملاً آفلاین (Self-Hosted):** عدم وابستگی به هیچ‌گونه اینترنت، CDN خارجی، یا سرویس‌های ابری (فونت‌ها و وابستگی‌ها همگی داخل بسته موجودند).
- **پشتیبانی از شبکه محلی (LAN):** دسترسی هم‌زمان چند کاربر از طریق رایانه‌های مستقر در سالن‌های تولید، مهندسی و مدیریت.
- **رابط کاربری صنعتی و واکنش‌گرا (RTL):** کاملاً فارسی به همراه پشتیبانی از تقویم جلالی و تم تاریک صنعتی متناسب با محیط کارگاهی.
- **تفکیک وظایف و سطوح دسترسی (۸ نقش کاربری):**
  1. **مدیرعامل (CEO):** تایید پیش‌فاکتورها، صدور دستور ساخت و مشاهده داشبورد کلان پیشرفت.
  2. **برنامه‌ریزی تولید و خرید (Planning):** استعلام قیمت، صدور سفارش خرید متریال/ریخته‌گری (PO) و تحویل نهایی به انبار.
  3. **مهندسی و R&D (Engineering):** بارگذاری نقشه‌ها، فایل‌های STEP و کدهای CNC برای هر مرحله از ساخت و بازبینی کیفیت.
  4. **کنترل کیفیت (QC):** ثبت برگه‌های بازرسی، تست‌های متالورژی و ابعادی و ثبت قطعات ضایعاتی یا سالم.
  5. **سرپرست تولید (Production):** تخصیص مراحل ساخت به ماشین‌آلات و صدور دستور کار برای شیفت‌ها.
  6. **اپراتور سالن (Operator):** ثبت شروع و پایان عملیات ماشین‌کاری، زمان‌سنجی و گزارش خرابی ایستگاه.
  7. **انبارداری و متریال (Warehouse):** تحویل‌گیری متریال اولیه، کسری قطعات و رهگیری موجودی.
  8. **مدیر ارشد زیرساخت (Super Admin):** پیکربندی کاتالوگ مدل‌ها، ماشین‌آلات، لیست قطعات (BOM)، کاربران و پشتیبان‌گیری پایگاه‌داده.

## 💻 نحوه نصب و راه‌اندازی در شبکه کارخانه

### ۱. پیش‌نیازها
- **Node.js**: نسخه 20 به بالا
- **NPM**: نسخه 10 به بالا

### ۲. نصب بسته‌ها
```bash
npm install
```

### ۳. اجرای سرور توسعه بر روی شبکه محلی (LAN)
```bash
# در محیط لینوکس یا مک:
./start.sh
# یا دستور مستقیم:
npm run dev

# در محیط ویندوز:
start.bat
```
سامانه بر روی پورت `3000` به صورت سراسری (`0.0.0.0`) اجرا می‌شود و سایر سیستم‌های متصل به وای‌فای یا کابل شبکه کارخانه می‌توانند با وارد کردن آدرس IP رایانه سرور (مثال: `http://192.168.1.50:3000`) به آن دسترسی داشته باشند.

### ۴. بررسی صحت کد و تست‌ها
```bash
# اعتبارسنجی تایپ‌ها و کدهای سیستم
npm run lint

# اجرای تست‌های واحد و Smoke Tests
npm test

# ایجاد نسخه آماده انتشار (Production Build)
npm run build
```
